How to publish on GitHub Pages
1. Download and extract this ZIP on your computer.
2. Open your existing GitHub repository for the website.
3. Upload the files and folders from inside the extracted `cleverbright-storyworks` folder to the repository root, replacing the previous versions when prompted.
4. Make sure `index.html` is at the repository root, not inside an extra nested folder.
5. Commit the changes and wait for GitHub Pages to rebuild the site.
6. Open the live website on desktop and mobile and check navigation, contact email, and images.
